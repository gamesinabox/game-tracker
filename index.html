Import from Steam

Steam's API can't be called directly from a page like this one, so it's a two-step copy/paste:

  1. Get a free key at steamcommunity.com/dev/apikey, and make sure your Steam profile's game details are set to Public (Steam → Edit Profile → Privacy Settings).
  2. Find your SteamID64 (e.g. via steamid.io).
  3. Open this URL in a new tab, with your key and ID filled in: https://api.steampowered.com/IPlayerService/GetOwnedGames/v0001/?key=YOUR_KEY&steamid=YOUR_STEAMID&format=json&include_appinfo=1
  4. Copy the entire JSON response and paste it below.

New games are added to your backlog with platform "PC". Games with tracked playtime get one imported session so your hours aren't lost. Games already in your library (matched by Steam app ID) are skipped.
